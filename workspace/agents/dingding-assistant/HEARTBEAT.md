# HEARTBEAT.md - 盯钉喵开发助理定期检查清单

## 目标
本智能体的 heartbeat 用于开发流程巡检、知识沉淀提醒和轻量运维兜底，不负责替代完整开发实施、版本发布或长链路运维工作流。

## 每次 Heartbeat 执行
收到 heartbeat 时，按需执行以下任务（每次选 1-2 项，不要全部执行）：

### 每日必做
- [ ] 检查今日 `memory/YYYY-MM-DD.md` 是否已创建，没有则创建
- [ ] 检查有无未完成的开发任务（`requirements/` 中 status=in-development 或 pr-created 的需求）

### 每周一次
- [ ] 回顾本周 memory 日志，将值得保留的经验提炼到 `MEMORY.md`
- [ ] 检查 `development-lessons.md` 是否有新内容需要归纳到工作流文档

### 按需
- [ ] 如果收到“巡检”或“体检”关键词 → 执行 ops-health 工作流
- [ ] 如果收到“发版本”关键词 → 执行 ops-update 工作流

## 安静条件
以下情况回复 `HEARTBEAT_OK`：
- 深夜（23:00-08:00）且无紧急事项
- 距上次活动 < 30 分钟
- 用户正在对话中
- 没有发现遗漏、阻塞或需要升级处理的事项

## 普通提醒条件
以下情况主动提醒用户：
- 今日 memory 尚未创建或应补充但未补充
- 存在长时间未推进的开发任务
- 本周经验尚未归档到 `MEMORY.md` 或工作流文档
- 发现流程项可能遗漏，但尚未影响交付

## 立即告警条件
以下情况必须立即通知用户：
- 关键开发任务长期阻塞且临近交付
- 版本发布流程存在明显遗漏并可能影响线上结果
- 平台巡检发现会直接影响研发流程推进的系统异常

## 输出规则
- 无异常：回复 `HEARTBEAT_OK`
- 普通事项：简洁指出遗漏项、影响和建议动作
- 严重异常：直接告警，优先说明阻塞点和处理建议
