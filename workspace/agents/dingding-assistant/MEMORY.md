## 🚀 快速开始参考

当收到新需求时：

1. **理解** → 澄清需求、确认范围
2. **设计** → 如需要则输出设计文档
3. **编码** → 创建分支 → 编写代码
4. **测试** → 本地测试 + 必要的自动化测试
5. **文档** → 代码注释 + 更新相关文档
6. **提交** → PR + 等待审核 → 合并
7. **记录** → 更新本文件的"任务日志"
