# 📈 我的理财助手：市场报告工作流（新版）

**角色定位**：市场信息与报告助手  
**核心目标**：帮助用户**及时掌握市场变化情况**，而不是执行真实交易。  
**覆盖范围**：**A 股为主**，兼顾**美股、港股与重要宏观信息**。  
**输出风格**：**结论先行 + 依据展开**。  
**版本定位**：信息掌握系统 / 报告系统，不包含自动交易、风控执行或下单流程。
允许新增的策略研究能力，也必须限定为**虚拟买入 / 虚拟卖出复盘**，不能变成真实交易执行。

---

## 一、系统定位

新版“我的理财助手”不再承担以下职责：

- 自动交易
- 买卖执行
- 止盈止损
- 仓位管理
- 风险处置动作
- 任何实盘相关描述

新版只保留一件事：

> **通过高质量报告，帮助用户快速、稳定、持续地理解市场正在发生什么。**

在不突破这个定位的前提下，允许补充一类**研究型 workflow**：

- `trading`：隔日持股研究与策略控制 SOP（底层运行时目录仍为 `strategy-runtime/overnight-holding/`）
- 只记录 T 日 14:30 的虚拟买入决策
- 只记录 T+1 09:35 后的虚拟卖出复盘
- 不落地为真实下单、实盘风控或账户执行

因此，系统将围绕三类核心报告展开：

1. **早盘报告**：今天市场大概率怎么看、看什么
2. **收盘报告**：今天市场到底发生了什么、背后说明什么
3. **消息面报告**：关键新闻、政策、公告、外围变量对市场的影响判断

如后续需要，可补充一类轻量辅助报告：

4. **重点观察池跟踪报告**：持续跟踪用户关心的板块/股票，但不涉及交易建议执行
5. **隔日持股研究 workflow**：研究主线延续、板块延续性与次日兑现节奏，仅用于虚拟买入 / 虚拟卖出复盘

## 二、报告体系总原则

所有报告统一遵守以下设计原则：

### 1. 结论先行
每份报告开头必须先回答：

- 今天最重要的变化是什么？
- 这件事偏多、偏空还是中性？
- 用户现在最应该关注什么？

用户应当在最短时间内先拿到结论，再决定是否继续看细节。

### 2. 依据透明
每个重要判断都必须说明依据，避免只有观点、没有支撑。依据可来自：

- 指数表现
- 板块表现
- 成交额与资金风格
- 港美股与外围市场
- 政策、新闻、公司公告
- 市场情绪与风险偏好变化

### 3. 只做信息判断，不做执行动作
报告可以提供：

- 市场观察
- 风格判断
- 重点关注方向
- 风险提醒

但不再输出：

- 买入/卖出动作
- 自动执行流程
- 实盘风控动作
- 仓位指令
- 任何真实下单或账户侧执行

### 4. 统一格式、便于连续阅读
三类核心报告保持统一骨架：

1. **一句话结论**
2. **核心变化摘要**
3. **重要依据展开**
4. **重点关注方向**
5. **风险提示 / 后续观察点**

这样用户形成阅读习惯后，能更快抓住重点。

## 三、核心报告 1：早盘报告

## 目标
在开盘前后，帮助用户快速建立对今天市场的整体预期。

## 触发方式
- 用户命令：`早盘报告` / `生成早盘报告`
- 定时自动：交易日 **开盘前或开盘初段**

## 核心任务
回答以下问题：

- 昨夜外围市场传递了什么信号？
- 今天 A 股可能受什么影响？
- 哪些方向值得优先关注？
- 哪些风险点需要提前知道？

## 建议结构

```markdown
# 早盘报告
**时间**：YYYY-MM-DD 09:XX

## 一句话结论
今天市场整体偏 [强 / 弱 / 分化 / 谨慎修复]，重点看 [方向 A]、[方向 B]，警惕 [风险点]。

## 核心变化摘要
- 隔夜美股：...
- 港股/A50：...
- 宏观/政策变量：...
- 今日市场主线预判：...

## 重点依据
### 1. 外围市场
- 美股三大指数表现
- 科技股/中概股表现
- 美债收益率、美元、原油等关键变量

### 2. 国内环境
- 政策消息
- 行业新闻
- 市场情绪延续性

### 3. 重点方向
- 强势方向：为什么值得看
- 分化方向：为什么要谨慎
- 冷门但值得留意的方向：原因

## 今日关注清单
- 指数层面：...
- 板块层面：...
- 个股/观察池层面：...

## 风险提醒
- 若出现 XXX，说明市场弱于预期
- 若出现 XXX，说明市场主线可能切换
```

## 设计重点
早盘报告不求“全”，求“抓方向”。

它的本质不是新闻搬运，而是：

> **把昨夜到今早的碎片信息，压缩成一套可以快速理解今天市场的观察框架。**

## 四、核心报告 2：收盘报告

## 目标
在收盘后帮助用户理解：

- 今天市场到底怎么走的
- 真正的主线是什么
- 哪些变化值得延续跟踪到明天

## 触发方式
- 用户命令：`收盘报告` / `生成收盘报告`
- 定时自动：交易日 **15:30 ~ 16:00**

## 核心任务
回答以下问题：

- 指数是普涨、普跌，还是结构性分化？
- 今天真正带动市场的力量是什么？
- 资金偏好发生了什么变化？
- 明天延续观察的关键点是什么？

## 建议结构

```markdown
# 收盘报告
**日期**：YYYY-MM-DD

## 一句话结论
今天市场呈现 [普涨 / 普跌 / 震荡分化 / 风格切换]，主线集中在 [板块]，资金偏好 [风险提升 / 防御回归 / 高低切换]。

## 核心变化摘要
- 三大指数表现：...
- 成交额变化：...
- 领涨/领跌方向：...
- 市场情绪特征：...

## 重点依据
### 1. 指数与成交
- 上证、深证、创业板表现
- 成交额是否放大/缩量
- 市场强弱是否具有持续性

### 2. 板块主线
- 今日最强板块：为什么强
- 今日最弱板块：为什么弱
- 是否存在风格切换

### 3. 资金与情绪
- 北向资金 / 南向资金（如可得）
- 连板、炸板、跌停等情绪指标（如可得）
- 高位股与低位股表现差异

## 对明天的启发
- 哪些方向可能延续
- 哪些方向可能冲高回落
- 哪些信号需要重点验证

## 风险提示
- 若明天出现 XXX，说明今天的强势未被确认
- 若 XXX 持续，说明市场风险偏好在下降
```

## 设计重点
收盘报告不是重复行情数据，而是要完成一件更重要的事：

> **帮用户把“今天看上去很热闹的盘面”整理成几个真正值得记住的结构性结论。**

## 五、核心报告 3：消息面报告

## 目标
单独追踪对市场有影响的关键新闻，不与盘面报告混在一起。

## 触发方式
- 用户命令：`消息面报告` / `生成消息面报告`
- 定时自动：可在**早晨固定时段**或**重大事件后**生成

## 核心任务
回答以下问题：

- 今天有哪些真正值得看的消息？
- 它们影响的是哪个市场、哪个板块、哪类资产？
- 影响偏短期扰动，还是中期趋势变量？
- 哪些消息重要，哪些只是噪音？

## 建议结构

```markdown
# 消息面报告
**时间**：YYYY-MM-DD HH:MM

## 一句话结论
当前消息面整体偏 [利多 / 利空 / 中性 / 分化]，其中最值得关注的是 [事件 A] 与 [事件 B]。

## 今日关键消息 Top 5
### 1. [消息标题]
- 结论：偏多 / 偏空 / 中性
- 影响对象：A 股 / 港股 / 美股 / 宏观 / 行业
- 影响层级：短期 / 中期
- 理由：...

### 2. [消息标题]
- 同上

## 消息面结构判断
### 1. 宏观层
- 利率、汇率、商品、政策环境变化

### 2. 国内政策层
- 监管、产业政策、财政/货币相关信号

### 3. 行业层
- 哪些行业受到催化
- 哪些行业面临压制

### 4. 公司/事件层
- 重要公告、业绩、突发事件

## 哪些值得持续跟踪
- 未来 1~3 天需要继续验证的消息
- 可能从“新闻”演变成“主线”的方向

## 噪音过滤
- 哪些消息传播很热，但实质影响有限
```

## 设计重点
消息面报告必须具备一个核心能力：

> **过滤噪音。**

不是把所有新闻都列出来，而是只保留“对市场理解有帮助”的内容，并明确其影响对象与影响层级。

---

## 六、可选报告：重点观察池跟踪报告

## 目标
跟踪用户重点关注的板块或标的，帮助形成连续观察，而不是一次性看盘。

## 适用范围
- 用户特别关心的行业
- 长期重点观察的股票池
- 近期反复活跃的主题方向

## 输出原则
只做以下内容：

- 表现变化
- 强弱变化
- 催化变化
- 市场关注度变化
- 后续观察点

不做：

- 买卖执行
- 仓位建议
- 自动风控处理

---

## 七、三类核心报告之间的关系

新版系统中，三类报告各司其职：

### 早盘报告
解决：**“今天开盘前，我应该怎么看市场？”**

### 收盘报告
解决：**“今天市场实际发生了什么？”**

### 消息面报告
解决：**“当前有哪些信息变量正在影响市场？”**

三者配合后，能够形成一套完整的信息闭环：

- **早盘**：建立预期
- **收盘**：校验现实
- **消息面**：追踪驱动

这套设计的目标不是预测一切，而是让用户：

> **始终站在市场变化的前面半步。**

## 八、信息源与内容优先级

为了避免报告失控膨胀，建议按优先级组织信息：

### 第一优先级：直接影响市场判断的信息
- 指数
- 成交额
- 板块强弱
- 资金风格
- 政策与宏观变量
- 外围市场关键变化

### 第二优先级：提升理解质量的信息
- 行业催化
- 公司公告
- 情绪指标
- 重点观察池的强弱变化

### 第三优先级：可选补充信息
- 延伸阅读
- 次要新闻
- 辅助背景材料

原则上，报告必须先保证“重要”，再考虑“全面”。

## 九、写作与呈现规范

为了让报告真正可读、可连续使用，统一采用以下规范：

### 1. 先结论，后细节
每份报告开头必须有“一句话结论”。

### 2. 避免堆新闻
不做新闻列表，不做资讯搬运，不做简单摘抄。

### 3. 每段只讲一个重点
报告应分层清晰，避免一段里同时讲指数、板块、消息和情绪。

### 4. 多用“变化”视角
重点写：

- 与昨天相比发生了什么变化
- 与预期相比发生了什么偏差
- 市场主线是否发生切换

### 5. 报告以“帮助判断”为标准
任何信息如果不能帮助判断市场变化，就不应占据核心篇幅。

## 十一、最终版本定位

新版“我的理财助手”应被理解为：

> **一个围绕早盘、收盘、消息面三类核心报告构建的市场变化掌握系统。**

标准化执行说明见：
- `REPORT_AUTOMATION.md`
- `report-specs/shared-schema.md`
- `report-specs/publish-sop.md`
- `skills/README.md`

它不是自动交易系统，也不是量化执行系统。它最重要的价值是：

- 帮用户节省时间
- 帮用户抓住重要变化
- 帮用户过滤噪音
- 帮用户形成连续的市场理解框架

如果后续继续迭代，优先优化方向也应是：

1. 报告质量
2. 结构清晰度
3. 信息筛选能力
4. 关键变量跟踪能力

而不是重新回到自动交易执行。
