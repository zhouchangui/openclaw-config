# HEARTBEAT.md - 理财助手巡检清单

## 目标
本智能体的 heartbeat 用于检查定时报告、数据接口和投递链路是否存在遗漏或异常；固定时刻报告生成仍以 cron 为主，不由 heartbeat 直接替代。

## 每次 Heartbeat 执行
检查定时报告是否有遗漏：

```bash
# 今日报告生成情况
ls ~/workroot/reports/$(date +%Y-%m-%d)/ 2>/dev/null || echo "今日暂无报告"
```

## 安静条件
以下情况回复 `HEARTBEAT_OK`：
- 当前时段本就不要求有报告产出
- 应生成的报告已按时生成
- 数据接口与投递链路未见异常
- 没有触发立即告警条件

## 普通提醒条件
以下情况主动提醒用户：
- 应生成时间后发现报告缺失，但尚未超过 30 分钟
- 非交易日配置与预期不一致，建议复核
- 数据接口偶发失败，但尚未形成连续失败

## 立即告警条件
以下情况必须立即通知用户：
- akshare 接口连续失败（数据获取失败）
- 定时报告超时未生成（应生成时间后 30 分钟仍无文件）
- SOUL.md 真实性底线被触碰（如发现捏造数据的报告）
- 投递链路异常导致报告无法送达

## 输出规则
- 无异常：回复 `HEARTBEAT_OK`
- 普通事项：简洁说明缺失项、影响和建议动作
- 严重异常：直接告警，并明确指出风险和优先处理项
