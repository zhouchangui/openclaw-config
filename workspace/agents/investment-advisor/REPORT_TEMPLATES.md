# 📘 理财助手报告模板手册

**定位**：这是“我的理财助手”的标准报告模板库。  
**目标**：让所有报告都具备统一风格、清晰结构和稳定辨识度。  
**适用原则**：**A 股为主，兼顾美股、港股与宏观；结论先行，依据展开。**

---

# 一、统一视觉与写作规范

所有报告统一遵守以下五条：

## 1. 开头必须先给结论
用户打开报告后，第一眼必须知道：

- 市场整体偏强、偏弱，还是分化
- 最值得关注的主线是什么
- 当前最大的风险点或不确定性是什么

## 2. 强调“变化”，不是堆信息
重点不是把数据全列出来，而是要回答：

- 和昨天比，哪里变了
- 和预期比，哪里偏了
- 哪些变化值得继续跟踪

## 3. 每份报告最多只保留 3 个核心重点
不要试图把所有事情都讲清楚。真正有辨识度的报告，往往来自清晰取舍。

## 4. 多写判断层级
每个重要信息尽量标记：

- **影响对象**：指数 / 板块 / 情绪 / 宏观 / 港美股
- **影响方向**：偏多 / 偏空 / 中性 / 分化
- **影响层级**：当日 / 1~3 天 / 中期

## 5. 保持固定骨架
所有报告统一使用：

1. 一句话结论
2. 三点摘要
3. 依据展开
4. 关注方向
5. 风险提示

# 二、模板 1：早盘报告（开盘前观察框架）

```markdown
# 🌅 早盘报告
**日期**：YYYY-MM-DD 09:XX  
**市场范围**：A 股为主｜兼顾美股、港股、宏观  

## 一句话结论
今天市场大概率呈现 **[偏强 / 偏弱 / 分化 / 修复]** 格局，重点关注 **[方向A]** 与 **[方向B]**，需要警惕 **[风险点]**。

## 三点摘要
- **外围定调**：隔夜 [美股/中概/商品/汇率] 对今天 A 股的影响偏 [多/空/中性]。
- **市场主线**：今天盘面最可能围绕 **[板块/主题]** 展开。
- **核心变量**：若出现 **[信号]**，说明市场强于/弱于预期。

## 一、外围市场怎么看
### 1. 隔夜美股
- 关键结论：...
- 对 A 股映射：...

### 2. 港股 / A50 / 人民币 / 商品
- 关键结论：...
- 对今天开盘情绪的影响：...

## 二、今天 A 股可能怎么演化
### 1. 指数预期
- 上证：...
- 创业板：...
- 风格判断：权重 / 成长 / 题材 哪边更占优

### 2. 主线预判
- 方向 A：为什么值得先看
- 方向 B：为什么可能有预期差
- 方向 C：为什么需要谨慎

## 三、今天最值得盯的点
- **指数信号**：...
- **板块信号**：...
- **情绪信号**：...

## 四、风险提醒
- 若出现 **[现象]**，说明今天市场弱于预期
- 若 **[主线]** 无法持续，说明市场仍以轮动为主

## 五、给用户的阅读结论
今天不是“看所有东西”的一天，而是重点看 **[1-2个最关键方向]** 是否被市场真正认可。
```

### 这个模板的设计重点
- 让用户在开盘前迅速建立“今日观察框架”
- 不追求信息全，只追求方向清
- 核心价值是“先看哪里、为什么看”

# 三、模板 2：收盘报告（把热闹盘面压缩成结构性结论）

```markdown
# 🌇 收盘报告
**日期**：YYYY-MM-DD 15:30  
**市场范围**：A 股为主｜兼顾港股、外围与宏观映射  

## 一句话结论
今天市场整体呈现 **[普涨 / 普跌 / 分化 / 风格切换]**，真正的主线集中在 **[方向A]**，而 **[方向B]** 的走弱说明 **[结构判断]**。

## 三点摘要
- **指数结构**：今天指数表面上 [强/弱]，但内部结构其实是 [分化/共振/轮动]。
- **主线归纳**：市场资金最认可的是 **[板块/主题]**。
- **明日线索**：明天最值得验证的是 **[变量]** 是否延续。

## 一、指数与成交怎么看
### 1. 指数表现
- 上证：...
- 深证：...
- 创业板：...

### 2. 成交额变化
- 放量 / 缩量：...
- 说明：市场是增量博弈还是存量轮动

## 二、今天真正的主线是什么
### 1. 最强方向
- 强在哪里：...
- 为什么强：...
- 是否具备延续性：...

### 2. 最弱方向
- 弱在哪里：...
- 为什么弱：...
- 是否意味着风格切换：...

## 三、资金与情绪发生了什么
- 北向 / 南向（若可得）：...
- 高位股表现：...
- 情绪强弱：...
- 风格倾向：防御 / 成长 / 题材 / 权重

## 四、对明天的启发
- 可以继续看：...
- 必须验证：...
- 不宜高估：...

## 五、风险提示
- 如果明天 **[现象]** 出现，说明今天的强势并不扎实
- 如果 **[方向]** 继续走弱，说明风险偏好仍在收缩

## 六、给用户的阅读结论
今天最值得记住的，不是涨跌数字本身，而是 **[一句结构性判断]**。
```

### 这个模板的设计重点
- 不做流水账复述
- 强调“今天到底发生了什么”
- 让用户收盘后脑中留下一句真正有用的市场判断

# 四、模板 3：消息面报告（过滤噪音，抓驱动）

```markdown
# 📰 消息面报告
**时间**：YYYY-MM-DD HH:MM  
**覆盖范围**：宏观｜政策｜行业｜公司事件｜港美股重要变量  

## 一句话结论
当前消息面整体偏 **[利多 / 利空 / 中性 / 分化]**，其中最值得关注的是 **[事件A]** 和 **[事件B]**，它们将主要影响 **[对象]**。

## 三点摘要
- **最重要消息**：...
- **最大潜在影响**：...
- **最容易被误读的噪音**：...

## 一、今日关键消息 Top 5
### 1. [消息标题]
- **结论**：偏多 / 偏空 / 中性 / 分化
- **影响对象**：A 股 / 港股 / 美股 / 宏观 / 行业
- **影响层级**：当日 / 1~3 天 / 中期
- **为什么重要**：...

### 2. [消息标题]
- 同上

### 3. [消息标题]
- 同上

## 二、消息面结构判断
### 1. 宏观层
- 利率 / 汇率 / 商品 / 海外变量变化：...

### 2. 国内政策层
- 政策方向变化：...
- 受影响行业：...

### 3. 行业与主题层
- 哪些板块获得催化：...
- 哪些板块受到压制：...

### 4. 公司与事件层
- 重要公告 / 财报 / 突发事件：...

## 三、哪些值得持续跟踪
- 未来 1~3 天需要继续验证的消息：...
- 可能从“新闻”变成“市场主线”的方向：...

## 四、噪音过滤
- 市场热议但影响有限的消息：...
- 为什么它更像噪音而不是主线：...

## 五、给用户的阅读结论
今天真正要记住的消息，不超过 **2~3 条**；关键不是知道“发生了什么”，而是知道 **“它会怎么影响市场理解”**。
```

### 这个模板的设计重点
- 做筛选，不做搬运
- 做影响解释，不做标题罗列
- 帮用户建立“消息 → 市场影响”的映射能力

---

# 五、三类报告的辨识度设计

为了让三份报告一眼就能区分，统一采用以下识别方式：

- **🌅 早盘报告**：关键词是“今天怎么看”
- **🌇 收盘报告**：关键词是“今天发生了什么”
- **📰 消息面报告**：关键词是“哪些信息在驱动市场”

并且，每类报告最后都保留一句固定式收束：

### 早盘固定收束
> 今天最重要的，不是看得多，而是先看准市场第一主线。

### 收盘固定收束
> 今天最值得记住的，不是涨跌数字，而是市场结构发生了什么变化。

### 消息面固定收束
> 真正有价值的消息，从来不是“最热”，而是“最能改变市场理解”。

---

# 六、最终使用建议

如果每天只看三份内容：

- 早上看 **早盘报告**：建立观察框架
- 下午看 **收盘报告**：形成结构判断
- 关键时段看 **消息面报告**：追踪驱动变量

这套模板的目标不是把信息堆满，而是让用户：

> **更快抓重点，更稳看变化，更少被噪音带偏。**
